Wearable PPG monitoring system

A wearable sensing system that brings optical acquisition, analog signal conditioning, real-time firmware, and digital signal processing onto a custom mixed-signal PCB.

The context

From design decisions to system behavior.

Optical PPG sensing starts with a small photodiode current. The design connects that analog measurement to deterministic sampling and digital processing, while accounting for the motion captured by an IMU.

My contributions

01

Analog signal chain

Designed a biased photodiode transimpedance amplifier, signal-conditioning circuitry, and analog filtering before a 24-bit ADC.

02

Mixed-signal integration

Architected a custom PCBA integrating the optical front end, ADC, IMU, ESP32-C3, BLE, and regulated power, with attention to grounding and low-noise routing.

03

Real-time acquisition

Developed ESP-IDF / FreeRTOS firmware with interrupt-driven SPI acquisition using ADC data-ready events and synchronized PPG and IMU sampling.

04

Embedded processing

Implemented a 101-tap FIR decimation pipeline and IMU-referenced NLMS processing intended to reduce motion artifacts. Developed C and Python tests for DSP precision, filter response, and acquisition behavior.

Project scope & evidence

Work spans circuit design, PCB integration, firmware, and hardware/software debugging with oscilloscopes and logic analyzers. Motion-artifact reduction is a processing objective; no quantified artifact-rejection result is claimed here.
