# Mohamed Ahmed — Engineering Portfolio

Personal electrical-engineering portfolio, including project writeups, STRIVE Medical leadership, professional experience, and downloadable resumes.

Website: https://mohamed0628.github.io

## Publish

In repository Settings → Pages, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The `.nojekyll` file allows the static HTML, CSS, JavaScript, and PDFs to be served directly.

## Structure

- `index.html`: portfolio home
- `projects/`: seven project pages
- `resumes/`: downloadable PDF resumes and CV
- `style.css`: responsive styles
- `main.js`: mobile navigation
- `404.html`: missing-page fallback

No package installation or build step is required. Update these files on the publishing branch to update the website.
